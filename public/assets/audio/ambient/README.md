# Per-Biome Ambient Soundscapes (CC0)

All ambient loop files in this directory are licensed under **CC0 1.0 Universal (Public Domain Dedication)** and map to `AMBIENT_MANIFEST` (`RoomEnvironmentId`) in `src/experience/audio/audio-constants.ts`.

To swap any biome loop with field recordings (e.g., from [Freesound CC0](https://freesound.org/search/?f=license:%22Creative+Commons+0%22)), keep the exact `.mp3` filename (seamless loop, mono 64–96 kbps recommended):
