# Museum UI Sound Effects (CC0)

All UI sound effects in this directory are licensed under **CC0 1.0 Universal (Public Domain Dedication)** and correspond to `SFX_MANIFEST` in `src/experience/audio/audio-constants.ts`.

To customize any effect, replace the target `.mp3` file keeping the exact same filename:

| File | Trigger (`SfxId`) | Description | Source / License |
|---|---|---|---|
| `reticle-hover.mp3` | `RETICLE_HOVER` | Soft wooden/glass hover tick | Procedural CC0 (replaceable with [Kenney Interface Sounds CC0](https://kenney.nl/assets/interface-sounds)) |
| `reticle-fuse.mp3` | `RETICLE_FUSE` | Gentle two-note gaze confirmation chime | Procedural CC0 |
| `stand-open.mp3` | `STAND_OPEN` | Warm ascending harmonic chime | Procedural CC0 |
| `stand-close.mp3` | `STAND_CLOSE` | Soft descending close chime | Procedural CC0 |
| `carousel-step.mp3` | `CAROUSEL_STEP` | Subtle slide navigation click | Procedural CC0 |
| `portal-whoosh.mp3` | `PORTAL_WHOOSH` | Filtered pink-noise portal transition sweep | Procedural CC0 |
| `hud-open.mp3` | `HUD_OPEN` | Hologram dashboard open fifth chime | Procedural CC0 |
| `hud-close.mp3` | `HUD_CLOSE` | Hologram dashboard dismiss chime | Procedural CC0 |
| `toggle-click.mp3` | `TOGGLE_CLICK` | Tactile audio preference toggle click | Procedural CC0 |
